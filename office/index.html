AIOS for brain と連携する

このオフィスは同じフォルダの office-status.json を2秒ごとに読み、社員が動きます。

① PC側: このリポジトリのフォルダで python sync.py を起動しておく(記録を自動でpushします)

② Claude Code に貼る指示:

作業を進める間、進捗を (このフォルダ)/office-status.json に随時書き出してください。各担当の作業開始時・完了時・エラー時に必ず更新します。スキーマ:
{
  "mission": "全体タスク名",
  "employees": {
    "dig": {"status":"working","task":"内容"},
    "kuro": {"status":"error","task":"承認待ち: 理由"}
  },
  "log": [{"time":"HH:MM","who":"dig","msg":"一行報告"}]
}
担当ID: judge=統括・裁定 / han=タスク分解・進行 / owl=設計・仕様 / zeni=コスト・モデル選択 / dig=調査・検索 / kuro=点検・原因調査 / niko=報告・要約 / new=実装。status は idle / working / done / error。log は末尾追加で最大30件。
