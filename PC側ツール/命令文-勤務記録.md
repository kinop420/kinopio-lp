# Claude Code / Codex に貼る指示(勤務記録)

以下をそのまま作業指示の冒頭に貼ってください。

---

このリポジトリの PC側ツール/office.py を使います。作業を進める間、必ず以下のルールで勤務記録を残してください。

1. 作業開始時に一度だけ:
   `python PC側ツール/office.py mission "今回の作業名"`
2. 各担当の作業を始める直前に:
   `python PC側ツール/office.py set <担当ID> working "やること"`
3. その担当の作業が終わったら:
   `python PC側ツール/office.py set <担当ID> done "終えたこと"`
4. ユーザーの承認・確認が必要になったら:
   `python PC側ツール/office.py set <担当ID> error "承認待ち: 理由"`
   (承認後は working か done に戻す)
5. 補足の一言報告(任意・キャラの口調は不要):
   `python PC側ツール/office.py log <担当ID> "一行報告"`

担当IDの対応(作業内容で選ぶ):
- dig = 調査・検索・情報収集
- owl = 設計・仕様・方針決め
- new = 実装・コード作成・ファイル編集
- kuro = 点検・テスト・原因調査
- han = タスク分解・進行管理
- zeni = コスト・モデル選択の判断
- niko = 報告・要約・ドキュメント作成
- judge = 全体の裁定・最終判断

記録は絶対に省略しないでください。工程が変わるたびに必ず set を実行します。
